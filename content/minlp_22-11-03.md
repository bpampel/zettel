### PhD thesis of Robert Burlacu



###

LP problems (linear problems) can be solved via the Simplex algorithm that finds the global optimum

Optimization problem: more variables than equations --> room for optimization

Can be viewed as a polytope (polygon, polyeder, ...), the optimal solutions then are on the extremal points (which correspond to "basic solutions")

The simplex algorithm moves on a path from extremal point to extremal point to find the solution.


### Glossary / terms to look up

 - "branch-and-bound"
 - NLP: nonlinear program
 - MIP: mixed-integer linear program
 - MINLP: mixed-integer nonlinear program
 - singular matrix: non-invertable quadratic matrix
 - feasible solution (zulässige Lösung): erfüllt Nebenbedingungen
 - dual linear problem: can be used to derive a bound (typically lower) for the primal problem. The two optima are equal.
